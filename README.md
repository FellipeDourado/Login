# Tela de Login

Projeto de desenvolvimento de uma tela de login, criado com foco na prática de desenvolvimento Front-End e na construção de uma interface organizada e funcional.

## Sobre o projeto

Este projeto consiste no desenvolvimento de uma tela de login utilizando tecnologias fundamentais do desenvolvimento web.

A aplicação foi estruturada separando HTML, CSS e JavaScript, permitindo uma organização mais clara dos arquivos e facilitando a manutenção do projeto.

## 🌐 Demonstração

[🔗 Acessar projeto](https://login-fellipe.vercel.app/)

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 📱 Responsividade

A interface foi desenvolvida de forma totalmente responsiva, adaptando seu layout para diferentes tamanhos de tela, incluindo dispositivos móveis, tablets e desktops.
